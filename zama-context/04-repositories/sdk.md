# Repository: sdk

## Role

Current TypeScript SDK for building confidential dApps on EVM-compatible chains.

## Observed capabilities

The README describes encryption, decryption, access-control interaction, shield/unshield flows, confidential transfers, framework-agnostic use with viem or ethers, and React support. It identifies `relayer-sdk` as the legacy SDK retained for reference.

## Research status

The SDK is a client-facing surface. A later pass should trace one SDK operation down into the host contract and protocol event lifecycle.
