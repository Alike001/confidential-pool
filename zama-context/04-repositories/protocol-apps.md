# Repository: protocol-apps

## Role

First-party applications and backend services built on the Zama Confidential Blockchain Protocol.

## Observed components

The README identifies confidential token wrappers, non-confidential operator staking, the ZAMA ERC20 token, and governance contracts. It is the application layer currently being kept separate from the lower-level FHEVM infrastructure.

## Research status

Application behavior will be studied after the protocol lifecycle is traced. The purpose is to distinguish infrastructure guarantees from choices made by first-party applications.
