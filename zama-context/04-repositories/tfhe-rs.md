# Repository: tfhe-rs

## Role

Zama’s Rust implementation of TFHE for Boolean and integer arithmetic over encrypted data.

## Observed capabilities

The repository README describes Rust, C, and client-side WASM APIs, programmable bootstrapping, integer APIs, compression, and production-oriented high-performance goals.

## Relationship to FHEVM

FHEVM depends on TFHE functionality for encrypted computation. FHEVM adds blockchain-facing handles, events, scheduling, consensus, access control, and decryption workflows around the cryptographic engine.
